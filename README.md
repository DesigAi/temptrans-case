# Кейс TempTrans

Публичная презентация проекта TempTrans для обращений к потенциальным клиентам. На компьютере открывается оригинальная PDF-презентация, на телефоне — десять вертикальных слайдов и отдельная кнопка PDF.

## Публичные ссылки

- Русская версия: https://temptrans-case.vercel.app/ru/
- Английская версия: https://temptrans-case.vercel.app/en/
- Корневая ссылка: https://temptrans-case.vercel.app/ — открывает русскую версию.

В папках `ru/` и `en/` находятся HTML, PDF, обложки ссылок, фото автора и мобильные слайды. Общие иконки находятся в корне. `vercel.json` сохраняет адреса страниц с завершающим `/`.

После обновления проверять обе языковые версии, PDF на компьютере, все слайды на телефоне, кнопку PDF, обложки ссылок и доступ к основным адресам без авторизации.
